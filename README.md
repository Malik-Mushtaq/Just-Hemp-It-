# Just Hemp It Storefront

Frontend storefront for Just Hemp It, built with React + Vite + TypeScript.

## Local development

Requirements:

- Node.js 18+
- npm

Run locally:

```sh
npm install
npm run dev
```

Production build:

```sh
npm run build
npm run preview
```

## Tech stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui

## Project notes

- Main HTML metadata/title is in `index.html`
- App routes are defined in `src/App.tsx`
- Product and variation API models are in `src/lib/api/product.ts`
